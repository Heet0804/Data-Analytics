# 📊 Excel Data Analytics

Five Excel projects that turn raw data into clear answers. Each project folder has its workbook and a README with the full write-up.

## 📁 Projects

| # | Project | Dataset | What it answers | Skills | Open |
|---|---------|---------|-----------------|--------|------|
| 1️⃣ | **Excel Salary Dashboard** | Data jobs (2023 postings) | What do data jobs pay by title, country and schedule type? | Charts, Formulas, Data Validation | [README](Project%20-%201%20Dashboard/README.md) |
| 2️⃣ | **Data Jobs Market Analysis** | Data jobs (2023 postings) | Do more skills mean better pay? Which skills are top, and what do they pay? | Power Query, Power Pivot, PivotTables, DAX | [README](Project%20-%202%20Analysis/README.md) |
| 3️⃣ | **IPL Analysis Dashboard** | 696 IPL matches (2008 to 2018) | Which teams, venues and players win most? Does the toss matter? | PivotTables, Slicers, XLOOKUP, GETPIVOTDATA | [README](Project%20-%203%20IPL%20Analysis/README.md) |
| 4️⃣ | **School Performance Dashboard** | 300 students (synthetic) | How do students do on marks, attendance and fees? | PivotTables, Slicers, GETPIVOTDATA, COUNTIFS, AVERAGEIFS | [README](Project%20-%204%20School%20Analysis/README.md) |
| 5️⃣ | **Bike Sales Dashboard** | 1,026 customers | Who buys a bike, by income, commute, age and region? | PivotTables, Slicers, Excel Tables, Nested IF | [README](Project%20-%205%20Bike%20Sales%20Analysis/README.md) |
